# 🔴 **白名单不是「豁免」** —— 探针对本清单里的用例做的是**更严**的判定：
#    ① C 侧读数必须**逐字节等于** `known-readings.txt` 里登记的形状
#       ⇒ 差异**形状变了**（哪怕还是不同）⇒ 判失败；
#    ② B 侧读数必须**逐字节等于** `expected.txt`（冻结锚）
#       ⇒ **B 侧（oracle）漂移了** ⇒ 判失败。
#    ⇒ ⇒ 净效果：**「允许不同」被钉成「只允许差这一处、且必须还是当初那一处」**。
