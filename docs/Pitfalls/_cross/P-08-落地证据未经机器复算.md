# P-08 · 「落地证据」没被机器复算 ⇒ 只是又一处沉默不变量

> 档位：跨模块（`_cross/`）· 首次登记 **2026-10-25** · 触发场景：A11 首次实跑

---

## 一、现象

`docs/决策记录.md` 的 **D1「落地证据」** 写着：

> `comment` / `like` / `favorite` 三域各含 `rpc/bootstrap/<域>FactDispatchScheduler`
> 与 `rpc/bootstrap/<域>AuthorityEndpointConfig`（共 6 个）**+ 三域各含 `rpc/bootstrap/<域>FactProcessLogging`**。

> 📌 **2026-10-26 · D10 补记（路径已变，结论不变）** —— 该装配包已由 `bootstrap/` 改名为 **`wiring/`**
> ⇒ 上面这段**原文引用**里的 `rpc/bootstrap/` 路径**已不存在**。
> ⚠️ 但**这条坑的成立性与包名无关**：缺的是 `comment` 域那**一份落点**，与它落在哪个包里**毫无关系**。

**这句话对 `comment` 域是假的** —— `comment` 域**没有** `CommentFactProcessLogging`，
只有 `like` / `favorite` 两域有。

⇒ 即：**三份进程级 logger 身份**（业务 RPC / fact-dispatch / fact-authority）里，
comment 域的 **2 份在 Java 侧没有任何落点**。

## 二、为什么会踩（这才是本档要记的）

| 环节 | 为什么没拦住 |
|---|---|
| **写台账时** | 「三域各含」是从**推导过程**抄下来的**意图**，不是从**文件系统**读出来的**事实** ⇒ 写的人没机会发现它不成立 |
| **编译时** | 缺的是**一个类**，不是缺一个**依赖** ⇒ **没有任何编译错误** |
| **测试时** | 树里全是空壳，**没有一行实现**可测 ⇒ **没有测试会红**（连写测试的人都不知道该测什么，因为落点根本不存在） |
| **review 时** | 台账那段读起来像**已核过的事实** ⇒ review 时**默认相信它** |
| **直到 2026-10-25** | A1–A12 落成可执行脚本（`tools/difftest/check-arch-invariants.py`）后**首次实跑** ⇒ A11 立刻红 |

⇒ **和 RAG `article-rpc` 的 2 颗哑弹是同款形态**：能力缺失 ⇒ 零编译错误 + 零测试红灯 + 台账还写着它有。

## 三、根因

> **一句话**：**「落地证据」这个字段名暗示了「它被核过」，但当时它没有任何东西会去核。**

一句话写下的 `证据`，和一句话写下的 `愿望`，在字节层面**完全一样**。

- 区别只在于**读者是否相信它**；
- 而**读者没有能力核**（核它需要逐个域打开树去找那个文件）⇒ **相信就等于放过**。

⇒ 与 **P-01（测试注入掩盖生产配置缺失）** 同一族：
> 凡是「**本该由机器复算**」的东西，**一旦靠人写下来**，就会**漂移**，
> 而且**漂移得毫无声响**。

## 四、判据（怎么才算核过）

| 判据 | 说明 |
|---|---|
| **可复算** | 结论必须能由**某个脚本**从**文件系统**重新算出来 |
| **可复跑** | 脚本要在**有意义的时机**跑（改结构后 / 提交前 / 合并前） |
| **会红** | 违反时**必须红** ⇒ 脚本自带 `--self-test`（造违规假树，验证判据确实会红） |
| **不靠启动日志** | 「注入点的 echo 照打、jar 照起、日志零告警，效果却是零」⇒ **判据要看运行时效果**（AGENTS.md §1.3） |

## 五、处置（本仓已落地）

| 项 | 内容 |
|---|---|
| **机器核** | `tools/difftest/check-arch-invariants.py` —— A11 逐域检查 `wiring/<域>{FactDispatchScheduler,AuthorityEndpointConfig,FactProcessLogging}` 三件套 |
| **会红** | `--self-test` 在临时假树上验证 **12/12 条判据均能红**（自证「断言不是摆设」） |
| **不把「没判」当「过了」** | 判据依赖实现内容时（如 A8 的 `implements org.slf4j.Logger`），空壳类报 **`PENDING`** 而**不是 `PASS`** ⇒ 杜绝「假绿」 |
| **补洞** | `comment-service/…/wiring/CommentFactProcessLogging.java` 已补 ⇒ 三域各 3 个落点齐备 |
| **台账订正** | D1「落地证据」加 **2026-10-25 补记**，明写「此前对 comment 域不成立」 |

## 六、留给下一域的提醒

> 写台账时，凡是能写成「**三域各含 X**」「**每个模块都有 Y**」这种**可数断言**的句子，
> **先问一句：这句话由谁复算？**
>
> - 没人复算 ⇒ 它是**愿望**，不是证据 ⇒ 要么补一个脚本，要么**在句子里写明它是推导意图**。
> - 已经写进台账却没人复算 ⇒ **补脚本**（这正是 A1–A12 的由来）。

⚠️ **反向也成立**：不要因为「这条台账没人核」就**删掉它**。
⇒ 台账的职责是**留下痕迹**；`DRIFT` / `Intentional_Deviations` / `Pitfalls` 三档的分工见 [`../../../AGENTS.md`](../../../AGENTS.md) §五。
