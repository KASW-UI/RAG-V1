# P-19 · JWT 是**确定性**的 ⇒ 同秒内同账号登录拿到的 token **逐字节相同** ⇒ 黑名单会「串味」到别的用例

> **登记时间**：2026-11-02（`align/users-admin` 工作树 · E-4 第二轮收尾时，`mvn -o -pl service/users/admin -am clean verify` **红了 1 例**）
> **性质**：**测试夹具隔离缺陷**（不是产品缺陷）—— 表现为**与执行顺序强相关的不稳定失败**
> **发现者**：`AdminHttpContractRealTomcatTest#protectedPathWithValidTokenIs200`「期望 200 实得 401」，
> 而**同一份代码**上一轮 `clean verify` 是 16/16 全绿 ⇒ ⇒ 先按「基线自带」处理，**再按同条件对照复跑定位**

## 一、形态

JWT 载荷 = `{uid, iat, exp}` ⇒ ⇒ **同密钥 + 同 uid + 同一秒 ⇒ 签出的是同一个字符串**。

本仓 HTTP 契约测试的登录夹具**每次都用同一个默认 admin 账号**
⇒ ⇒ uid 固定 ⇒ **唯一的变量是 `iat`（秒级）**
⇒ ⇒ **同一秒内**两次登录 ⇒ token **完全相同**。

而「token 进黑名单」那条用例会把
`admin:jwt_blacklist:<token>` 写进 Redis（**无 TTL**）
⇒ ⇒ **同一秒内**后续用例再登录，拿到的**就是那个已经被拉黑的 token**
⇒ ⇒ 后续用例莫名 **401**（日志里不是验签失败，而是
`AdminJwtAuthInterceptor : admin token in blacklist`）。

⇒ ⇒ **症状**：某条「带合法 token ⇒ 期望 200」的用例**偶发** 401，
**且复现与否取决于「它跑在黑名单用例之后、且两者落在同一秒」**。

---

## 二、为什么它特别难查（三层）

1. **它不是每次都红**：跨秒 ⇒ token 不同 ⇒ 不串味 ⇒ **上一轮全绿、这一轮红**。
2. **错误信息指向错的地方**：报的是 `401 UNAUTHORIZED`，
   而真正的日志线索是**拦截器的黑名单告警**（不是验签告警）⇒
   不翻日志就会去查「验签 / 密钥 / claims」——**全查错方向**。
3. **只跑单个类 vs 跑全量，结论会相反**（本仓同轮实测）：
   - 基线副本只跑 `-Dtest=AdminHttpContractRealTomcatTest` ⇒ **红**（1 failure）；
   - 同一份基线跑**全量** `clean test -fae` ⇒ **16/16 全绿**。
   ⇒ ⇒ 「单类红」**不能**代表「全量也红」，反之亦然
   ⇒ ⇒ **两侧必须用逐字相同的命令形态对照**（这是判定「本轮引入 vs 基线自带」的前提）。

---

## 三、判定式（可复用）

1. ⇒ ⇒ **凡测试夹具里「登录拿 token」，先问「这个 token 是不是**每次都一样**」**
   ⇒ ⇒ JWT 默认**是** ⇒ ⇒ **同一秒内重复登录 ⇒ 同一个 token** ⇒ ⇒
   **任何按 token 做的状态隔离（黑名单 / 幂等键 / 限流桶）都会串味**。
2. ⇒ ⇒ **凡要断言「某 token 被拉黑 ⇒ 401」**，断言完必须**清理**那个 key
   （或让夹具保证「我拿到的 token 不在黑名单里」）。
3. ⇒ ⇒ **别把「偶发 401」当成验签问题**：先看拦截器日志里是
   `admin token in blacklist`（**黑名单**）还是 `admin JWT verify failed`（**验签**）—— 两者的修法完全不同。
4. ⇒ ⇒ **JWT 确定性本身要有一条**可执行的**机制守卫**（不是靠注释记住）：
   本仓加的是 `jwtIsDeterministicForSameClaims`（同参数 ⇒ 逐字节相同；iat+1 ⇒ 必须不同）⇒
   变异检验：若 `JwtUtil` 哪天引入随机 nonce ⇒ 该断言**立刻变红**。

## 五、同族

- 「**『跑绿』≠『本来就绿』**」「**红灯要同条件对照**」

  且**必须用同形态命令复跑**才能把「本轮引入 vs 基线自带 vs 时序偶发」三者分开。

  ⇒⇒ 本条的机制守卫正是按 P-12 的要求配了**变异检验**（随机 nonce ⇒ 变红）。
- 「**零命中的读数 ⇒ 先证明命令本身成功**」
  ⇒⇒ 本条同源：**「单类红 / 全量绿」不是矛盾，是两种不同口径**（同轮实测）。
