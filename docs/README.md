## 二、三档台账的关系

```
「RAG-V1 与 Go 不一致」        → DRIFT/          （待查）
「明知不同、签字批准」          → Intentional_Deviations/  （决策，不是缺陷）
「为什么会踩」                 → Pitfalls/       （元教训）
「主动放弃某一层语义」         → L3-降级清单.md  （不可反向修回）
```

⚠️ **四者不可混谈。** 把降级项写进 Intentional_Deviations，会让它看起来"可以修回"。
