# 注解速查表

> 范围：本仓库 `service/**` 中**实际使用**的注解。示例取自现有代码，只保留理解用法所需的最小片段。
> 说明：本仓库持久层统一用 MyBatis-Plus，**不使用** JPA（`@Entity` / `@Id` / `@GeneratedValue` 等只出现在对照注释里）；软删除也**刻意不用** `@TableLogic`，而是在 Mapper 里显式写 `delete_at IS NULL`。
> 测试专用注解单独放在最后一节。
>
> 大致的流程：Controller → Service → Mapper（持久层）→ 数据库

## 一、Spring Bean 与依赖注入

- `@Component`：通用 Bean 标记，标记类。
  `@Component public class LikeRpcMetrics {}`
- `@Service`：业务逻辑层 Bean（表示这个 Component 是专门用来写业务逻辑的）。
  `@Service public class LikeDomainService {}`

- `@Configuration`：配置类，Bean 的自定义源，下面写一堆 Bean
  `@Configuration 
-  public class WebMvcConfig implements WebMvcConfigurer {
  - @Bean
  - @Bean
- }`

- `@Bean`：方法返回值注册为 Bean，标记方法。
  `@Bean public ObjectMapper objectMapper() { ... }`

- `@Autowired`：依赖注入；本仓库主代码以构造器注入为主，测试里常见字段注入，以下示例为构造器注入。
- 以以下为例，这是把 registry 的所需依赖全部初始化，只剩下 registry 进行手动初始化
- `@Autowired`
-  public UserRpcMetrics(MeterRegistry registry) { 
  - this.registry = registry;
- }`

- `@Qualifier`：按名称限定同类型 Bean，以下面为例，只初始化 applicationTaskExecutor，其他不进行初始化 
  `@Qualifier("applicationTaskExecutor") TaskExecutor taskExecutor`
- `@Value`：从配置文件注入配置值，支持默认值。
  `@Value("${spring.cloud.nacos.discovery.server-addr:127.0.0.1:8848}") String addr`
- `@Import`：显式导入配置类 / Bean 类，不扫描整个包。
  `@Import({SnowflakeBean.class, RpcServerInterceptorFactory.class})`

- `@Lazy`：延迟创建 / 注入代理对象，常用于打断循环依赖和延迟创建。
- 延迟创建：等到有人第一次需要它时再创建
- 循环依赖：Spring 创建 A 时要 B，创建 B 时又要 A，可能死循环报错。
-         加了 @Lazy 后，Spring 给 A 注入的不是真的 B，而是一个“占位代理”：
-         A 先拿到这个代理，启动不报错；
-         等 A 真正调用 bService.xxx() 时，代理才去容器里找真正的 B。
  `public ... factory(@Lazy HotEventConsumer consumer) { ... }`

- `@DependsOn`：声明 Bean 初始化顺序，一般注解在 @Bean 下方。
  `@DependsOn("adminSchemaBootstrap")`
- `@Order`：同一类型多个 Bean 的排序（Filter / 拦截器常用），
-  给组件编号，从小到大，按照执行一个事件时的执行顺序。
  `@Order(Ordered.HIGHEST_PRECEDENCE + 6)`

- `@ComponentScan`：指定扫描包，可配排除规则。
  `@ComponentScan(basePackages = {"com.rag.task.task.api", "com.rag.common"}, excludeFilters = { ... })`

## 二、启动、配置与自动配置

- `@SpringBootApplication`：启动类组合注解（配置 + 自动配置 + 组件扫描）,
- `@SpringBootConfiguration`、`@EnableAutoConfiguration`、`@ComponentScan` 的合体。
  `@SpringBootApplication public class LikeRpcApplication {}`

- `@SpringBootConfiguration`：声明配置类；测试里用来拼最小应用上下文。
  `@SpringBootConfiguration @EnableAutoConfiguration static class GateApplication {}`
- `@EnableAutoConfiguration`：开启 Spring Boot 自动配置（测试最小上下文常用）。
  `@SpringBootConfiguration @EnableAutoConfiguration static class GateApplication {}`
- `@EnableDiscoveryClient`：注册到服务发现（本仓库为 Nacos）。
  `@EnableDiscoveryClient public class LikeApiApplication {}`
- `@EnableScheduling`：开启 `@Scheduled` 定时任务，扫描所有 @Scheduled 的方法，并把它们注册成定时执行的任务。
  `@EnableScheduling public class LikeRpcApplication {}`
- `@EnableTransactionManagement`：显式开启注解事务代理；测试配置中用于贴近生产装配。
  `@EnableTransactionManagement(proxyTargetClass = false) static class TestConfig {}`
- `@EnableConfigurationProperties`：让指定 `@ConfigurationProperties` 类生效。
  `@EnableConfigurationProperties(LikeApiProperties.class)`
- `@ConfigurationPropertiesScan`：扫描并注册配置属性类。
  `@ConfigurationPropertiesScan(basePackages = "com.rag.like.like.rpc.config")`
- `@ConfigurationProperties`：把配置前缀绑定到 POJO。
  `@ConfigurationProperties(prefix = "follow") public class FollowRpcProperties {}`
- `@NestedConfigurationProperty`：声明嵌套配置对象（内部类属性）。
  `@NestedConfigurationProperty private UserAuth userAuth = new UserAuth();`
- `@DefaultValue`：配置缺失时的默认值（对应上游 struct tag 里的 default）。
  `public ListConf(@DefaultValue("20") int defaultLimit, @DefaultValue("100") int maxLimit) { ... }`
- `@AutoConfiguration`：声明自动配置类，可指定 before / after 排序。
  `@AutoConfiguration(after = DataSourceAutoConfiguration.class, before = MybatisPlusAutoConfiguration.class)`
- `@ImportAutoConfiguration`：只导入指定自动配置（测试常用）。
  `@ImportAutoConfiguration(DataRedisAutoConfiguration.class)`
- `@ConditionalOnWebApplication`：仅 Web 应用生效；本仓库限定 Servlet。
  `@ConditionalOnWebApplication(type = ConditionalOnWebApplication.Type.SERVLET)`
- `@ConditionalOnProperty`：按配置开关决定是否装配 bean。
  `@ConditionalOnProperty(prefix = "comment.authority", name = "enabled", havingValue = "true")`
- `@ConditionalOnMissingBean`：容器缺少该 Bean 时才创建（默认兜底实现）。
  `@ConditionalOnMissingBean(ContentSecurityPort.class)`
- `@ConditionalOnClass`：classpath 存在指定类时才生效。
  `@ConditionalOnClass({GrpcGlobalClientInterceptor.class, ManagedChannel.class})`
- `@DependsOnDatabaseInitialization`：等数据库 schema 初始化完成后再创建 Bean。
  `@DependsOnDatabaseInitialization public class AdminSeederBootstrap {}`

## 三、Web / HTTP

- `@RestController`：HTTP 控制器，返回值直接写响应体，@Controller + @ResponseBody 的合体，
- `@Controller`：声明这是控制器，处理 HTTP 请求
- `@ResponseBody`：方法返回值序列化后直接写响应体（通常是 JSON）
  `@RestController @RequestMapping("/like/v1") public class LikeController {}`

- `@RestControllerAdvice`：全局统一异常处理 / 全局统一响应包装，
- `@ControllerAdvice` + `@ResponseBody` 的合体，
- `@ControllerAdvice`：拦截所有 Controller 的异常/数据，交给统一的方法处理
- `@ResponseBody`：方法返回值序列化后直接写响应体（通常是 JSON） 
  `@RestControllerAdvice public class GlobalExceptionHandler {}`

- `@RequestMapping`：类级或方法级路径前缀。
  `@RequestMapping("/comment/v1")`
- `@GetMapping`：GET 映射。
  `@GetMapping("/article/{id}")`
- `@PostMapping`：POST 映射。
  `@PostMapping("/getlikecount")`
- `@PutMapping`：PUT 映射。
  `@PutMapping("/article/{id}")`
- `@DeleteMapping`：DELETE 映射。
  `@DeleteMapping("/folder/delete")`
- `@RequestBody`：JSON 请求体绑定；本仓库大量使用 `required = false` 以对齐 B 侧的宽松解析。
  `@RequestBody(required = false) GetLikeCountReq req`
- `@RequestParam`：查询参数 / 表单参数绑定。
  `@RequestParam(name = "incr_view", required = false) String[] incrView`
- `@PathVariable`：路径变量绑定。
  `public GetArticleResp getArticle(@PathVariable("id") String id, ...)`
- `@ExceptionHandler`：处理指定异常，配合 `@RestControllerAdvice` 使用。
  `@ExceptionHandler(AuthenticationException.class) public ResponseEntity<Void> handle(...)`

## 四、持久层（MyBatis / MyBatis-Plus）
### 持久层：代码和存储之间的中间处理层

- `@Mapper`（`org.apache.ibatis.annotations`）：标记 MyBatis Mapper 接口。
  `@Mapper public interface UserMapper extends BaseMapper<UserEntity> {}`
- `@MapperScan`（`org.mybatis.spring.annotation`）：批量扫描 Mapper 包。
  `@MapperScan("com.rag.like.like.rpc.mapper")`
- `@Select` / `@Insert` / `@Update` / `@Delete`：注解式 SQL，写在 @Mapper 下。
  `@Select("SELECT * FROM users_user WHERE uid = #{uid} LIMIT 1")`
  `@Insert("INSERT INTO like_consume_inbox (...) VALUES (...)")`
  `@Update("UPDATE like_outbox_event SET status = 1, updated_at = now() WHERE event_id = #{eventId}")`
  `@Delete("DELETE FROM follow_relation WHERE user_id = #{userId} AND target_id = #{targetId}")`
- `@Param`：给 SQL 中的 `#{name}` 绑定方法参数名，将参数名暴露给 MyBatis。
  `int deleteByPair(@Param("userId") long userId, @Param("targetId") long targetId);`
- `@Options`：主键回填等 JDBC 选项。
  `@Options(useGeneratedKeys = true, keyProperty = "id")`
- `@Results` / `@Result`：手写结果映射；本仓库主要用于 JSON 字段的 TypeHandler，将 java 名和 json 名连接起来。
  `@Results({ @Result(property = "extraInfo", column = "extra_info", javaType = Map.class, typeHandler = JsonTextTypeHandler.class) })`
- `@ResultMap`：复用已定义的 @Results。
  `@ResultMap("articleEntityResultMap")`
- `@TableName`：MyBatis-Plus 表名映射；`autoResultMap = true` 让字段级 TypeHandler 生效。
  `@TableName(value = "users_user", autoResultMap = true)`
- `@TableId`：主键映射与主键策略，声明主键。
  `@TableId(type = IdType.ASSIGN_ID)`（雪花 ID）
  `@TableId(type = IdType.INPUT)`（外部传入主键，如事件 ID）
- `@TableField`：列名 / TypeHandler 映射，字段和列的映射。
  `@TableField(value = "extra_info", typeHandler = JsonTextTypeHandler.class)`
- `@Intercepts` + `@Signature`：MyBatis 插件（拦截 SQL 执行，如超时翻译）。
- `@Intercepts`：MyBatis 的插件（拦截器）注解，作用是声明一个类去拦截 MyBatis 执行过程中的某个关键动作，在动作真正执行前后插入你自己的逻辑
- `@Signature`：三要素，拦截谁（type）、拦截哪个方法（method）、方法参数是什么（args，用来精确匹配重载方法）
  `@Intercepts({ @Signature(type = Executor.class, method = "query", args = { ... }) })`
- `@MappedTypes`：注册 TypeHandler 支持的 Java 类型。
  `@MappedTypes(Map.class) public class JsonTextTypeHandler extends BaseTypeHandler<Map<String, String>> {}`

## 五、事务
### 数据库概念，要么全部成功，要么全部失败

- `@Transactional`：声明式事务，可指定回滚异常、传播行为、隔离级别，。

- `@GrpcService`：把实现类注册为 gRPC 服务。

## 七、Kafka、定时任务与生命周期

- `@KafkaListener`：声明 Kafka 消费者。
  `@KafkaListener(id = "like-update-consumer", topics = "${like.kafka.like-topic}", groupId = "${spring.kafka.consumer.group-id}", containerFactory = "kafkaListenerContainerFactory")`
- `@Scheduled`：定时执行，按照设定规则定时执行；本仓库用它替代上游的 goroutine + ticker。
  `@Scheduled(fixedRateString = "${like.outbox-relay-interval:1000}") public void sendPending() { ... }`
- `@EventListener`：监听 Spring 事件；本仓库监听 `ApplicationReadyEvent` 做注册 / 建表校验。
  `@EventListener(ApplicationReadyEvent.class) public void register() { ... }`
- `@PostConstruct`：Bean 初始化后执行（启动后台线程 / 调度器 / 日志）。
  `@PostConstruct public void start() { ... }`
- `@PreDestroy`：Bean 销毁前执行（停止线程 / 释放资源）。
  `@PreDestroy public void stop() { ... }`

## 八、JSON 序列化（Jackson）

> 本仓库同时存在 Jackson 2 与 Jackson 3 注解：`com.fasterxml.jackson.annotation.*` 与 `tools.jackson.databind.annotation.*`，不要混用。

- `@JsonProperty`：指定 JSON 字段名（本仓库大量用于对齐 B 侧的 snake_case）。
  `@JsonProperty("conversation_id") private long conversationId;`
- `@JsonInclude`：控制空值是否输出。
  `@JsonInclude(JsonInclude.Include.NON_NULL)` / `@JsonInclude(JsonInclude.Include.NON_EMPTY)`
- `@JsonIgnore`：忽略某字段，不参与序列化 / 反序列化。
  `@JsonIgnore private boolean extraInfoPresent;`
- `@JsonIgnoreProperties`：类级忽略未知字段或指定字段。
  `@JsonIgnoreProperties(ignoreUnknown = true)` / `@JsonIgnoreProperties(ignoreUnknown = false)`
- `@JsonFormat`：字段格式；本仓库用于把 long 型 ID 输出成字符串。
  `@JsonFormat(shape = JsonFormat.Shape.STRING) private long id;`
- `@JsonPropertyOrder`：固定 JSON 字段顺序，对齐上游 `encoding/json` 的 struct 字段序。
  `@JsonPropertyOrder({"msg_id", "user_id", "target_type", "target_id"})`
- `@JsonAutoDetect`：控制 getter / 字段可见性；用于避免把 `Throwable.getMessage()` 等继承 getter 输出成多余字段。
  `@JsonAutoDetect(getterVisibility = JsonAutoDetect.Visibility.NONE, isGetterVisibility = JsonAutoDetect.Visibility.NONE)`
- `@JsonDeserialize`（`tools.jackson.databind.annotation`）：指定自定义反序列化器。
  `@JsonDeserialize(using = GoStyleFloat64Deserializer.class) private Double weight;`

## 九、Lombok

> ⚠️ **本仓规则（D18）**：Lombok **允许 + 鼓励**；但**凡被 Lombok 简化掉的「原本的完整代码」，必须以 `/** */` 注释原样写在该 Lombok 注解的正上方** ⇒ 机器判定 = **A13**。
> ⇒ 完整规范（逐场景表 / 写法细则 R1–R7 / 展开模板 / 正反例）⇒ [`docs/Lombok-使用规范.md`](../docs/Lombok-使用规范.md)。

- `@Data`：生成 getter / setter / equals / hashCode / toString 等。
  `@Data @TableName("admin_admin") public class AdminEntity {}`
- `@Getter` / `@Setter`：单独生成 getter / setter。
  `@Getter @Setter public class Response { ... }`
- `@NoArgsConstructor`：生成无参构造器（Jackson / MyBatis 反序列化常需要）。
- `@AllArgsConstructor`：生成全参构造器。
- `@RequiredArgsConstructor`：只对 `final` / `@NonNull` 字段生成构造器。
- `@Builder`：生成建造器（替代「一堆 setter」）。

**标准写法（展开块贴在注解正上方）**：

```java
/**
 * <p><b>B 出处</b>：……（§3.2 三段式照旧）
 *
 * <p><b>Lombok 展开（不用 Lombok 时的完整代码）</b>：
 * <pre>{@code
 * public class Xxx {
 *     private Long id;
 *
 *     public Long getId() { return id; }
 *     public void setId(Long id) { this.id = id; }
 * }</pre>
 */
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
public class Xxx {
    private Long id;
}
```

⛔ **DTO 层禁用**（D5 + A9 要 immutable record）· ⚠️ **`@Slf4j` 默认不用**（拿不到 `GoStyleLogger` 的 B 侧 `call_chain` 字段 · A8）· ⛔ **`@SneakyThrows` 禁用**（吞异常 ⇒ 破坏错误契约）。
**依赖**：各模块自带 `lombok`（`provided`）+ 显式 `annotationProcessorPaths`（JDK 23+ 否则**静默失效**）。

## 十、JDK 内置

- `@Override`：声明重写父类 / 接口方法，编译期校验。
- `@FunctionalInterface`：声明函数式接口（只允许一个抽象方法）。
  `@FunctionalInterface public interface LogOption { ... }`
- `@SuppressWarnings`：抑制编译告警；本仓库常见于资源未关闭、未检查转换等场景。
  `@SuppressWarnings("resource")`
- `@Deprecated`：标记废弃成员，保留兼容。
  `@Deprecated private boolean taskPushersEnabled = true;`

## 十一、测试专用

### JUnit 5 基础

- `@Test`：测试方法。
- `@DisplayName`：测试类 / 方法的可读名称；本仓库大量用于写清「B 侧对照点」。
  `@DisplayName("DRIFT-MSG-V-024：DB / 未知异常必须走 UNKNOWN")`
- `@BeforeEach` / `@AfterEach`：每个测试前后执行。
- `@BeforeAll` / `@AfterAll`：整个测试类前后执行一次（通常配合 `static`）。
- `@Nested`：嵌套测试类，按场景分组。
- `@Timeout`：测试超时保护。
  `@Timeout(value = 60, unit = TimeUnit.SECONDS)`
- `@TestMethodOrder`：指定测试方法顺序。
  `@TestMethodOrder(MethodOrderer.OrderAnnotation.class)`

### 参数化测试

- `@ParameterizedTest`：参数化测试方法。
  `@ParameterizedTest(name = "secret={0}B ⇒ alg 必须是 HS256")`
- `@ValueSource`：直接提供参数值。
  `@ValueSource(ints = {15, 16, 31, 32, 36, 47, 48, 63, 64, 65, 128})`
- `@MethodSource`：从方法提供参数。
  `@MethodSource("productionClientNames")`
- `@CsvSource`：用 CSV 提供多列参数。
  `@CsvSource(delimiter = '|', value = { "'{\"user_id\":\"1902\",\"cur\":3}' | 1902 | 3 | true" })`

### Spring 测试上下文

- `@SpringBootTest`：启动 Spring 上下文做集成测试。
  `@SpringBootTest(classes = LikeRpcApplication.class, webEnvironment = SpringBootTest.WebEnvironment.NONE)`
- `@AutoConfigureMockMvc`：自动配置 MockMvc。
- `@LocalServerPort`：注入真实启动的随机端口，用于真实 Tomcat 测试。
  `@LocalServerPort private int port;`
- `@TestConfiguration`：测试专用配置类。
  `@TestConfiguration(proxyBeanMethods = false) static class Props {}`
- `@TestPropertySource`：测试专用属性覆盖。
  `@TestPropertySource(properties = "article-rpc.article-sync-outbox.poll-interval-ms=0")`
- `@SpringJUnitConfig`：用指定配置类启动 Spring 测试上下文。
  `@SpringJUnitConfig(ArticleOutboxRelayScheduleTest.Config.class)`

### Testcontainers 与条件跳过

- `@Testcontainers`：开启 Testcontainers 生命周期管理。
- `@Container`：标记容器字段（通常为 `static final`）。
  `@Container static final PostgreSQLContainer<?> PG = new PostgreSQLContainer<>("postgres:16-alpine");`
- `@DynamicPropertySource`：把容器地址等动态值注入 Spring 配置。
  `@DynamicPropertySource static void datasource(DynamicPropertyRegistry r) { r.add("spring.datasource.url", PG::getJdbcUrl); }`
- `@EnabledIfDockerAvailable`：无 Docker 时自动跳过测试。
- `@EnabledIfEnvironmentVariable`：按环境变量决定是否执行。
  `@EnabledIfEnvironmentVariable(named = "PROBE_GO_TARGET", matches = ".+")`

### Mock

- `@MockitoBean`：替换容器中的 Bean 为 Mock。
  `@MockitoBean private LikeRpcClient likeRpcClient;`
- `@MockitoSpyBean`：保留真实 Bean，同时允许 spy / verify。
  `@MockitoSpyBean private StringRedisTemplate redisTemplate;`
